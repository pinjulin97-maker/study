## Goal

- Solve a few real problems (2–3 is plenty), write up the working, and commit once a day (same daily streak as [atlas](https://github.com/pinjulin97-maker/atlas) and arbiter).
- Quality over quantity — a couple of hard problems beats dozens of easy ones.

## How to use

One problem (or a small set) per file, inside the matching subject's unit folder. Suggested naming `YYYY-MM-DD-short-description.md`, e.g.:

```
maths-aa-hl/5-calculus/2026-11-04-chain-rule-practice.md
physics-hl/D-fields/2026-11-05-capacitor-problem.md
```

Copy [TEMPLATE.md](TEMPLATE.md) as a starting point for each note. Add a line to [LOG.md](LOG.md) after each session.

> Unit folder names follow the IB syllabus — rename, add, or remove them anytime.
