## Goal

- Read at least one unit, write something down, and commit once a day (same daily streak as [atlas](https://github.com/pinjulin97-maker/atlas) and arbiter).
- Capture concepts, worked examples, and mistakes so the notes still make sense on review.

## How to use

One topic/problem per file, inside the matching subject's unit folder. Suggested naming `YYYY-MM-DD-short-description.md`, e.g.:

```
maths-aa-hl/5-calculus/2026-11-04-chain-rule.md
physics-hl/D-fields/2026-11-05-electric-field-and-potential.md
```

Copy [TEMPLATE.md](TEMPLATE.md) as a starting point for each note. Add a line to [LOG.md](LOG.md) after each session.

> Unit folder names follow the IB syllabus — rename, add, or remove them anytime.
